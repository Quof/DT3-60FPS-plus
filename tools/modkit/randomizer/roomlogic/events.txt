# Events: things the game remembers that open a way somewhere else. A requirement names one as "event <name>" (the
# room files show it as event:<name>, on the gate or barrier that waits for it). solve.py works out what each event
# needs from these lines and puts that in its place, over and over till nothing changes. A line is one way an event
# happens (several lines for one event: any of them is enough):
#   <event> room <room> [: <requirements>]     getting into that room (any way in), then what else it takes there
#   <event> area <number> [: <requirements>]   getting into any room of that area
# Requirements are as everywhere else (README.txt): djump, megaman 2, attack, key 3...

# a Nightmare Gate's boss beaten (its character in eGateProg goes to 8, then 9 once its instrument's taken): the
# Sacred Temple's doors, one a gate. Getting into the boss's room is its fight, which bosses.txt says what it takes.
# Gate H is cut from the Randomizer: its access gate (in the destroyed Hidden Village, there once the other seven are
# beaten) goes to the mod's blank room for it (mod\rooms\rRndGateH), which counts the gate as beaten and goes on to the
# Sacred Temple (where its instrument is)
gateH room rHiddenVillage_Destroyed : event gateA event gateB event gateC event gateD event gateE event gateF event gateG
