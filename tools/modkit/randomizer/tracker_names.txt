# Check Tracker names (the mod's tracker\checks.html): the tab and the screen each room's checks are listed under,
# as the player knows them (the game's own names: the area banners, the teleport menu's places, Gate 4's stage map,
# the jukebox's titles; a room's number is its own place in its group, a letter as its place in the alphabet).
#   <room> = <tab> | <screen>
# Tabs show in the order they first come here, screens in the order they're listed. A room with checks that isn't
# here goes under its area's name (rndgen.py lists them when it builds). Rooms listed with the same tab and screen
# share one. A check's own name (else it's named by its type, with where it is in the screen when the screen has
# several of that type):
#   check <type> <objectNum> = <name>        (type as locations.csv has it: Heart Piece, Treasure Chest, ...)
