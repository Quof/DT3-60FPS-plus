# Last-resort changes to the Randomizer's logic: what the player needs to reach a location, replacing what the room
# logic worked out (roomlogic\roomlogic.txt). Most changes belong in roomlogic\overrides.txt instead: a change there is
# to a way through a room, and everything past it follows (roomlogic\README.txt). rndgen.py reads this file; build
# again after changing it. locations.csv lists every location with what it needs.
#
# A line replaces what one location, or every location in a room, needs:
#   <location type> <number>: <requirements>      heart piece 12: djump gdash
#   room <room>: <requirements>                   room rMain_2: djump | adash, key 3
# Location types are as locations.csv names them (heart piece, treasure chest, skill point, weapon upgrade, key...).
# Requirements: alternatives separated by |, any one of which is enough; each the items it takes, separated by spaces
# or commas:
#   gdash (dash), adash (air dash), djump (double jump), hijump N (High Jump Boots, 1 or 2), mario (the Mario Ability
#   Set), link N, belmont N, megaman N, samus N, gamej N, gamec N (that many of an ability set's items: link 2 = the
#   Master Sword and the Bow & Arrow), key N (the key of the locked door whose objectNum is N: doors.csv)
# or nothing (jumping alone), or everything (no ability or key is ever placed there).
# A room's line applies first, then a location's own line replaces it. A line only changes that location: rooms past
# it aren't changed with it.
