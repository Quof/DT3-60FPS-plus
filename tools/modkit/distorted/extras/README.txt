DISTORTED MODE for DT3+
=======================

Distorted mode is Spinach's remix of Distorted Travesty 3 (made from DTFree 1.0.10): the whole game with harder rooms
full of hex rings and traps, changed bosses, enemies and equipment, new areas and its own DLC. This folder is it
converted into a DT3+ mod. It runs at DT3+'s frame rates (30, 60 and 120fps).

To play: put this folder in DT3+'s Mods folder, turn it on on the title screen (Mods), start the game again, and start
a new game. It changes the whole game, so play it without the other mods that change the game's rooms: Altered
Insanity's Virtual Insanity and Altered Beast change many of the same rooms and objects, and Virtual Insanity's area
has the same location number as Distorted's Hexring Hell.

A save made with the original Distorted mode loads with its Distorted progress, unless it was saved in one of
Distorted's new rooms. DT3+ keeps Distorted's progress in its own section of the save file.

The mod changes most of the game's rooms and objects, so the game takes longer to start with it on than with smaller
mods. Mods\mod_log.txt has how long each part of loading took.


MUSIC
-----

Distorted's music isn't included. Copy the .ogg files from the Music folder of your Distorted mode download into this
folder's music folder (Mods\Distorted\music; mod.ini's [music] section lists the file names). Until they're there, the
tracks Distorted replaced play as the game's own, and its new tracks (the DLC's and others) are silent. Where a track's
source is known, the pause menu credits it while it plays.


DIFFERENCES FROM THE ORIGINAL
-----------------------------

  Gate E's fast room    Nightmare Gate E's "Gotta go fast" room: the original raised the frame rate to 60 there. In
                        DT3+, where 60 and 120fps are frame rate options, the game runs at twice its speed in that room
                        instead, with the sound and music at double pitch as in the original.
  Swap type             Distorted's "Thematic" swap type (Link with Belmont, Mega Man with Samus) is DT3+'s "Standard
                        (Fixed)", which pairs the sets the same way.
  Restart music         Restart Music on Death is one of DT3+'s options too: the mod leaves it as you have it.
                        Distorted's default was Off.
  Boss gallery          As in the original, the Executive's door fights Distorted's Brian Machine, and its record and
                        medal times are kept as the Executive's.


A WARNING FROM THE ORIGINAL
---------------------------

The Lava Cave's Lower Passage tells you not to get a game over there. If you do, as in the original, the game saves
to a file of its own in the Saves folder (you_dumbnut.dts, or an_idiot_is_you.dts if you were already playing that
one), puts a new game in your save slot and closes. To get your progress back, rename that file to your slot's
(DT3data.dts for slot 1, DT3data2.dts to DT3data5.dts for slots 2 to 5).


report.txt says what was converted and how.
