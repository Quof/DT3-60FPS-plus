16) held left/right keep going through screen transitions (not a dipswitch; scrKeyCarry explains it)
	GM forgets held keys on a room change and only the key pressed last comes back (Windows key repeat), so holding right and then pressing jump stopped the player on the next screen
	a left/right key (the bound key or the arrow key) held when the room changes, and still held, counts as held until it's let go
	oKeyCodesHighFPS Step and Room End note the held keys, Room Start carries them, scrKeyboardCheck reads them with keyboard_check_direct (only while the window has focus)
	every io_clear() is followed by scrKeyCarryClear(), so menus/messages that clear the keys still drop them like before
	only left/right: other held buttons are still forgotten on room entry
	also: rExtGateB_1 has an oKeyCodesHighFPS placed in it; that extra copy now destroys itself (its scrGamepadInit put the gamepad controls back to the defaults)

17) SOCD: Last Input Priority (dipswitch 408, global.socdLastInput, on by default)
	left+right or up+down held at once: only the one pressed last counts; the other takes over again when that one is let go (if it's still held)
	both pressed on the same frame: right wins, up for up/down (global.socdTie, set in scrGamepadInit)
	scrController 1-4 go through scrSOCD, which reads the directions with scrDirHeld (keyboard and gamepad together: what scrController returned for them before)
	the press order is tracked on every check, with the dipswitch off too; off = both count at once, as in the original
	everything that reads directions through scrController follows it: the player, menus, minigames, Show Key State

	the New Game and Continue code moved to oInitializeGame's user events 2 and 3

	preview panel: sFilePanel frame 0 = the original panel, for normal saves and empty slots (no MODE: the modes stay secret until the game is beaten); 1-4 = green (Easy), red (Achilles), dark purple (Nightmare), black with crimson vines (Night Terror: Nightmare + Achilles), with GAME TIME shortened and MODE next to it
